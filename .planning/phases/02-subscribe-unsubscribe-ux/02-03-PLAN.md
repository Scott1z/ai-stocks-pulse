## Locked decisions this plan implements

- **D-01** — soft-ask is NOT on page load; it appears after a dwell timer. Value: **6000 ms** (`02-UI-SPEC.md` locked 6s within CONTEXT.md's ~5-10s discretion band). No return-visit gate: first-time visitors are eligible.
- **D-02** — the soft-ask is the bottom banner from `02-02`, never a modal, never blocking.
- **D-03** — the persistent control is `#pushToggle` in the topbar.
- **Discretion, resolved:** once dismissed via ×, the soft-ask **never auto-reappears** — not later in the session, not on a future visit. The flag persists in `localStorage` (`aisp_push_soft_ask_seen`), not `sessionStorage`. The only path back is a deliberate `#pushToggle` click. This is FEATURES.md's anti-nagging rule and Chrome's grant-rate heuristic (02-RESEARCH.md Pitfall 4) working together.
- **Discretion, resolved:** the topbar toggle click in the `default` state is itself an explicit, deliberate opt-in gesture — it is the sanctioned second entry point to the native prompt. OPTIN-02 is satisfied because the native prompt fires from exactly these two affirmative gestures and from nowhere else, never automatically.
